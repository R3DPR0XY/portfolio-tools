# Segurança

[English version](SECURITY_EN.md)

Antes de publicar qualquer código neste repositório, revise se existe informação sensível.

## Nunca publicar

- Chaves de API.
- Tokens de acesso.
- Senhas.
- Cookies.
- Arquivos `.env`.
- Dados pessoais ou de clientes.
- Caminhos locais sensíveis.

## Recomendação

Use arquivos `.env.example` para demonstrar nomes de variáveis sem expor valores reais.
