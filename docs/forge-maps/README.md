# R3DPR0XY Forge Maps

**English first. [PT-BR](#r3dpr0xy-forge-maps-pt-br) below.**

Forge Maps are original R3DPR0XY technical showcase maps. They are designed for READMEs, GitHub profiles, release notes, and portfolio case studies.

## Formats

| Format | Purpose | Example |
| --- | --- | --- |
| Release Rail | Shows how source changes become tested artifacts or public releases. | [GitHub Actions Release Rail](github-actions-release-rail.html) |
| Runtime Core | Shows how a plugin turns player/admin actions into server behavior. | [MPersonagem Runtime Core](mpersonagem-runtime-core.html) |
| Mod Circuit | Shows how a Fabric mod connects loader, entrypoint, mixins, screens, assets, and JAR output. | [Kagerov Mod Circuit](kagerov-mod-circuit.html) |
| Showcase Board | Turns a project into a product-like public snapshot. | [Portfolio Tools Showcase Board](portfolio-tools-showcase-board.html) |

## Install The Skill

From this repository:

```bash
npx skills add https://github.com/R3DPR0XY/portfolio-tools --skill r3dpr0xy-forge-maps
```

The reusable skill lives in [`skills/r3dpr0xy-forge-maps`](../../skills/r3dpr0xy-forge-maps).
