# R3DPR0XY Forge Maps v0.1.0

First public version of the R3DPR0XY Forge Maps format.

## What Is Included

- A reusable Codex skill: `r3dpr0xy-forge-maps`
- Four original map formats:
  - Release Rail
  - Runtime Core
  - Mod Circuit
  - Showcase Board
- A GitHub Actions Release Rail example for the portfolio pipeline.
- Documentation for using Forge Maps as project showcase assets.

## Why It Exists

Forge Maps turn technical repositories into recognizable public presentation assets. The goal is to make mods, plugins, release flows, and portfolio projects easier to understand and easier to trust.

## Install

```bash
npx skills add https://github.com/R3DPR0XY/portfolio-tools --skill r3dpr0xy-forge-maps
```
