# DraxxLink - Curriculo Tecnico

Desenvolvedor focado em mods, plugins e ferramentas para Minecraft, com experiencia pratica em Java, Fabric, Paper, Gradle, Maven, interfaces client-side, sistemas de servidor e documentacao tecnica.

## Perfil

Crio projetos tecnicos voltados a resolver problemas reais dentro de jogos e servidores: interfaces customizadas, automacoes, sistemas de roleplay, configuracoes avancadas e ferramentas de produtividade. Meu foco e transformar ideias em software funcional, organizado e facil de manter.

## Competencias

- Java para mods e plugins.
- Fabric API e desenvolvimento client-side.

- Gradle e Maven.
- Estrutura de projetos publicos no GitHub.

## Experiencia pratica demonstrada

### Desenvolvimento client-side

Projetos como Kagerov, LootPanel e Betterchat mostram uso de Fabric, mixins, recursos visuais e interacao com telas do Minecraft. Esses projetos exigem entendimento do ciclo de renderizacao, eventos do cliente, estrutura de recursos e organizacao de codigo.

### Sistemas de servidor

MPersonagem mostra criacao de um plugin Paper com comandos, menus, permissoes, configuracoes editaveis e dados persistidos por jogador. O projeto tambem considera integracoes opcionais como PlaceholderAPI e TAB.

CreditsRewards mostra uma camada mais comercial de plugin: economia propria, missoes, lojas via NPC, persistencia em SQLite/MySQL e separacao entre vitrine publica e codigo-fonte privado.

### Design tecnico e documentacao

Void Sentinel mostra capacidade de organizar um sistema jogavel completo: identidade visual, balanceamento, habilidades, dependencias, instalacao e testes. O foco e transformar uma ideia de gameplay em um pacote tecnico compreensivel.
