# Estudo de Caso - Betterchat

## Resumo

Betterchat e um mod Fabric client-side voltado a melhorar a experiencia de chat no Minecraft com interface propria, contatos e historico.

## Problema

O chat padrao e simples para conversas recorrentes, contatos e organizacao de mensagens. Para servidores sociais ou de roleplay, uma interface mais direta pode melhorar a comunicacao.

## Solucao

O projeto cria uma camada de interface para organizar contatos, registros de conversa e a experiencia de interacao com mensagens.

## Pontos tecnicos

- Estrutura de mod Fabric.
- Classes dedicadas para contato, historico e tela.
- Interface customizada com estados visuais.
- Recursos de idioma em JSON.

## O que demonstra

- Modelagem simples de dados de UI.
- Criacao de uma experiencia client-side alem do padrao do jogo.
- Separacao de responsabilidades entre tela, contatos e registros.
