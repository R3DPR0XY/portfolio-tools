# Case Study - Betterchat

[Versao em portugues](betterchat.md)

## Summary

Betterchat is a client-side Fabric mod focused on improving the Minecraft chat experience with its own interface, contacts, and history.

## Problem

The default chat is simple for recurring conversations, contacts, and message organization. For social or roleplay servers, a more direct interface can improve communication.

## Solution

The project creates an interface layer to organize contacts, conversation records, and the message interaction experience.

## Technical Points

- Fabric mod structure.
- Dedicated classes for contact, history, and screen.
- Custom interface with visual states.
- Language resources in JSON.

## What It Demonstrates

- Simple UI data modeling.
- Creation of a client-side experience beyond the default game behavior.
- Responsibility separation between screen, contacts, and records.
