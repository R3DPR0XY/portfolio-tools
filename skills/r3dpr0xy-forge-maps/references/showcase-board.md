# Showcase Board

Use for portfolio case studies, README hero diagrams, project summaries, and client-facing technical overviews.

## Inspect

- README
- case study docs
- source tree
- workflow files
- release artifacts
- project metadata

## Layout

Put the project value in the center. Surround it with four edge panels:

- `FEATURES`: what users get
- `STACK`: tech used
- `PROOF`: builds, tests, releases, artifacts
- `DELIVERY`: where the project can be used or downloaded

This is closer to a product card than a system diagram. It should make the project feel finished.

## Labels

Use outcome-first wording:

- `Roleplay character system`
- `Book editing toolkit`
- `Server-ready plugin`
- `Automated JAR release`
- `Portfolio case study`

## Finish

Add a short claim under the title: one sentence explaining why the project matters.
