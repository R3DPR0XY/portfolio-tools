# Balance Presets

## PvE Dungeon

Use quando a classe for para dungeon, boss fight e servidor RPG.

- Shield Throw: dano 8-12, cooldown 4-5s
- Void Guard: resistencia 5s, cooldown 12-15s
- Singularity Chain: raio 6-7, cooldown 14-18s
- Warden's Verdict: stun 25-35 ticks, cooldown 10-14s
- Event Horizon: dano 16-24, stun 30-45 ticks, cooldown 45-60s

## PvP Controlado

Use quando jogadores podem lutar entre si.

- Shield Throw: dano 5-7, cooldown 6-8s
- Void Guard: resistencia 3-4s, cooldown 18-22s
- Singularity Chain: raio 4-5, cooldown 20-26s
- Warden's Verdict: stun 10-18 ticks, cooldown 16-22s
- Event Horizon: dano 8-12, stun 15-25 ticks, cooldown 70-90s

## Overpowered Boss Reward

Use se a classe for recompensa rara.

- Shield Throw: dano 12
- Void Guard: absorcao forte
- Singularity Chain: raio 8
- Warden's Verdict: stun 35 ticks
- Event Horizon: dano 24 e cura 12
