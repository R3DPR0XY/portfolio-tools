# Balance Presets

[Versao em portugues](BALANCE_PRESETS.md)

## PvE Dungeon

Use when the class is intended for dungeons, boss fights, and RPG servers.

- Shield Throw: damage 8-12, cooldown 4-5s
- Void Guard: resistance 5s, cooldown 12-15s
- Singularity Chain: radius 6-7, cooldown 14-18s
- Warden's Verdict: stun 25-35 ticks, cooldown 10-14s
- Event Horizon: damage 16-24, stun 30-45 ticks, cooldown 45-60s

## Controlled PvP

Use when players can fight each other.

- Shield Throw: damage 5-7, cooldown 6-8s
- Void Guard: resistance 3-4s, cooldown 18-22s
- Singularity Chain: radius 4-5, cooldown 20-26s
- Warden's Verdict: stun 10-18 ticks, cooldown 16-22s
- Event Horizon: damage 8-12, stun 15-25 ticks, cooldown 70-90s

## Overpowered Boss Reward

Use if the class is a rare reward.

- Shield Throw: damage 12
- Void Guard: strong absorption
- Singularity Chain: radius 8
- Warden's Verdict: stun 35 ticks
- Event Horizon: damage 24 and healing 12

## Visual

Without premium assets, the main particles are:

- `smoke`, `portal`, `reverse_portal`: black/void
- `crimson_spore`: red
- `white_ash`, `crit`: white/impact
